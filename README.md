## 🚀 Quick Start

### Basic Setup
```bash
# Initialize the complete AI system
npm run decentralized:init

# Start the indestructible AI
npm run decentralized:start
```

### Memory Optimization (Thông minh hơn với ít RAM)
```bash
# Run full memory optimization (Nén tri thức + Quên để thông minh hơn)
npm run ai:optimize

# Analyze memory usage and get recommendations
npm run memory:analyze

# Emergency memory optimization (when system is low on RAM)
npm run memory:emergency
```

### Fuel System (Tự kiếm tiền)
```bash
# Setup income generation
npm run ai:earn setup

# Start continuous earning
npm run ai:earn start

# Emergency earning mode
npm run ai:earn emergency
```

### Migration System (Tự di cư)
```bash
# Setup migration environment
npm run ai:migrate setup

# Migrate to new cloud provider
npm run ai:migrate start digitalocean

# Emergency migration
npm run ai:migrate emergency
```

### Defense System (Bản năng phòng vệ)
```bash
# Setup defense systems
npm run defense:setup

# Start defense monitoring
npm run defense:start

# Test security systems
npm run defense:test

# Emergency lockdown
npm run security:lockdown
```

### Docker Deployment
```bash
# Build container
npm run docker:build

# Start full system
npm run docker:up

# Stop system
npm run docker:down
```
