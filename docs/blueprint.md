# **App Name**: OpenMind

## Core Features:

- Local LLM Management: Allow users to discover, download, and manage various local Large Language Models, similar to a model 'store'.
- Interactive Chat Interface: Provide a clean, modern chat interface for users to interact with their loaded local LLM.
- Model Switching: Enable seamless switching between different installed local LLMs during a conversation or for new prompts.
- Prompt Generation & Refinement: A tool to help users craft and refine their prompts, ensuring better outputs from the chosen LLM.
- Conversation History: Maintain a history of user conversations with each LLM, stored locally for future reference.

## Style Guidelines:

- Primary color: A vibrant indigo-violet (#7A2BD4) to symbolize intelligence and advanced technology.
- Background color: A very dark, desaturated indigo (#25202D) for a modern, sophisticated dark theme.
- Accent color: A bright sky blue (#63A5FF) to highlight interactive elements and provide contrast.
- Headline and Body text font: 'Inter', a grotesque-style sans-serif, for a modern, objective, and clean aesthetic.
- Utilize sleek, minimalist, and outline-style icons to maintain a 'modern technology' feel across the application.
- Implement a modular and adaptive layout, allowing users to customize pane sizes for chat, model selection, and prompt management. Focus on spaciousness and clear hierarchy.
- Incorporate subtle and smooth transition animations for loading states, model switching, and chat message appearance to enhance the interactive experience without distraction.
